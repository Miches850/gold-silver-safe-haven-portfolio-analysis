# Outputs

When `code/analysis_portable.R` is executed successfully from the repository root, the script is configured to write its Excel workbooks to this folder.

Expected filenames include:

- `PortfolioOptimization_Results.xlsx`
- `Rolling_Crisis_PortfolioResults.xlsx`
- `Regional_PortfolioResults.xlsx`
- `Regional_Rolling_Portfolios.xlsx`
- `Stage3_GlobalRegional_Summary.xlsx`

These generated outputs are not included here because the current environment does not have R installed and therefore cannot independently rerun/validate the original analysis.
