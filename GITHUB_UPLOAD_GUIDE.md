# GitHub Upload Guide

## Recommended repository name
`gold-silver-safe-haven-portfolio-analysis`

## Recommended description
R-based financial-economics capstone comparing gold and silver as safe-haven assets across crises and regions using drawdowns, rolling risk metrics, portfolio optimization, and dynamic allocations.

## Upload order
1. Create the repository as **Private**.
2. Upload all files in this package.
3. Open `README.md` and confirm the figure previews render correctly.
4. Review `docs/REPRODUCIBILITY_NOTES.md`.
5. Verify the U.K. index identity.
6. Verify the redistribution rights for `data/Master_of_Data_Indeed_v3.xlsx`.
7. If data redistribution is not allowed, remove the workbook and replace it with source instructions.
8. If possible, add any missing script/workbook used to generate Figures 16-21 and Tables 5-6.
9. Make the repository public only after those checks.

## GitHub profile pin
Once public, pin this repository to your profile.

## Resume wording after publication
A safe project line is:

**Gold vs. Silver Safe-Haven & Portfolio Risk Analysis | R**  
Evaluated gold and silver across U.S. and international equity/bond markets using weekly returns, drawdowns, volatility, rolling risk measures, mean-variance optimization, crisis-specific allocations, and regional portfolio comparisons.

Avoid describing the repository as a live trading system or professional portfolio-management experience.
